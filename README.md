# Button Microinteraction

Exercício de UX/UI focado nos pequenos estados de um botão de ação.

## O que demonstra

- resposta visual à posição do ponteiro;
- estado de foco visível para teclado;
- feedback depois da ação;
- suporte a `prefers-reduced-motion`;
- tipografia e contraste simples para manter o foco na interação.

## Rodando localmente

```bash
git clone https://github.com/Santoszoi/efeito-houver.git
cd efeito-houver
python -m http.server 8000
```

Abra `http://localhost:8000`.

HTML, CSS e JavaScript sem frameworks.
